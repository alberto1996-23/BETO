# BETO.app
My personal digital portfolio where I showcase all my projects and experiences.
Built using React.Js. Hosted on Firebase.

## Stack

- Frontend: React.Js
- Backend: N/A

### Prerequisites

- React and Vite installed

### Deployment

git clone the BETO repo and run using 'npm run dev'

```bash
git clone https://github.com/alberto1996-23/BETO.git
cd beto
npm run dev
```
